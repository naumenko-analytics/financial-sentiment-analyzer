# Financial Sentiment Analyzer
AI-powered financial news sentiment analysis using RAG, LangChain, and OpenAI GPT.

## What it does
- Fetches real-time financial news for any company via NewsAPI
- Builds a FAISS vector knowledge base from news articles
- Uses RAG to retrieve the most relevant articles for analysis
- GPT-3.5-turbo analyzes sentiment and returns structured insights

## Tech Stack
Python, LangChain, OpenAI GPT-3.5, FAISS, Streamlit, NewsAPI
