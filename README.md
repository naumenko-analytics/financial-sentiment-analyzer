# Financial Sentiment Analyzer
AI-powered financial news sentiment analysis using RAG, LangChain, and OpenAI GPT.

## What it does
- Fetches real-time financial news for any company via NewsAPI
- Builds a vector knowledge base using FAISS and OpenAI embeddings
- Uses RAG to retrieve the most relevant articles for a given question
- Returns sentiment analysis and summary with sources cited

## Tech Stack
Python, LangChain, OpenAI GPT, FAISS, Streamlit, NewsAPI
